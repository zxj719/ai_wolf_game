ROS2 入门 · 第 1 周

这是一份给零基础实习生的全自学课程。你不需要有 ROS2、Linux 或 Python 经验， 但需要按顺序一天一天走完——每一天都建立在前一天的产出之上。

你会学到什么

  • 独立创建、编译、source 一个 ROS2 workspace，并说清楚 package 里每个文件干什么用
  • 独立编写 launch 文件，熟练使用 namespace 与 remap
  • 深入理解 Topic：类型体系、message 结构、发布频率、QoS；会用 rosbag 录制与回放
  • 接通真实的 Livox Mid-360 激光雷达，在 rviz2 里看到点云
  • 手写 URDF/xacro 描述一台带 2D lidar 与 IMU 的差速小车，并在 Gazebo 中跑起来

第 2 周会在你自己造的这台小车上，做 slam_toolbox 建图与 Nav2 导航。

环境要求

项要求
操作系统Ubuntu 22.04（x86_64），非虚拟机优先
ROS2 发行版Humble
仿真器Gazebo Fortress (Ignition)，Day 4 才需要
编程语言Python（rclpy）。本课程不写 C++

本课程只针对 ROS2 Humble。网上大量教程是 Jazzy 或 Foxy 的，命令与写法都有差异，照抄会出错。遇到冲突时以本课程和 Humble 官方文档为准。

怎么用评分脚本

评分脚本不会替你启动节点。正确的顺序是：你先把自己的节点跑起来， 然后另开一个终端执行脚本。脚本会连上 ROS2 网络，检查话题、类型、频率、 节点名等是否符合考卷要求。

# 终端 1：先启动你自己的节点
cd ~/ws_intern
source install/setup.bash
ros2 run day1_exam talker

# 终端 2：再跑评分
cd ~/ws_intern
source install/setup.bash
python3 ~/Tutorials4intern/grading/grade_day1.py

脚本失败时不会只告诉你扣分，而是会打印期望什么、实际测到什么、建议怎么查。 先读这三行，再去改代码。

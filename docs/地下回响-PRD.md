# 地下回响 / Underground Echoes

产品需求文档 · v0.8 · 2026-10-27

**清扫，重建，连接。玩家清出的地下空间，就是人们生活和争夺的世界。**

本文以最新的独立房间穿梭、自由首击、单格大本营和手势架桥规则为准。用户已撤回多格根据地要求；3×3 / 4×4 大本营方案作废。此前传统塔防方案停止推进；v0.1 保存在同目录供追溯。当前为本地可玩原型，数值与剧情需要持续试玩校准。

## 1. 产品方向

以扫雷判断驱动回合，以人物关系驱动行动的理由。先体验开出安全格的即时反馈，再关心如何守住这块地，最后理解外出清扫与后方补给的联系。新玩家一次只面对当前需要的系统。

灵感取自《死亡搁浅》的连接、旅途和物流约束，使用原创人物、地点、对白和技术名称，不移植其专有世界设定。主页以小说工作台和狼人杀为主要作品入口；小游戏单独承载深度体验，避免长篇自我介绍。

## 2. 当前交付与后续边界

| 模块 | 当前可玩实现 | 后续建设 |

### 2.1 当前故事的节奏和停止线

新局主线不要求扫完 127 间。下文的大地图、培养、迁驻和跨区战斗是已有自由探索系统；它们不再作为开局需要掌握的清单。旧远征保留原有开放状态。

| 玩家正在做的事 | 自然转折与玩家选择 | 当前开放内容 |
| --- | --- | --- |
| 在旧站台找一块干净地面 | 任意首击、读数字、开格和标记；需要时主动打开九宫格练习 | 纯扫雷，后台不增长势力、不空降敌军 |
| 第一间房已经清完 | 清区庆祝后，林渡招呼玩家回来安顿；可以先穿门继续走，也可以接听 | 接听结束后，在刚才的房间出现灰帆探路人；雷位、地形和清扫成果保留 |
| 守住这块地 | 划桥、驻扎、数字收益、补给与进攻；玩家主动结束回合 | 只显示连接地图；演示也使用“结束回合”，不再要求同时扫雷 |
| 敌方据点被实际占领 | 岑灯提议留下守桥，玩家主动接话后出门 | 左侧清扫新房，右侧显示刚守住的桥头；一次清扫让后方走一回合 |
| 第一条新的供给路清通 | 电台传来烧水的声音，可以回去歇脚 | 当前故事收束；明确告知内容已结束。退出存档，或自选自由探索 |

“玩家疲劳”是设计判断，当前没有假装能识别情绪的计时器。以实际完成一件事后的停顿提供变化，由玩家决定是否接；不在清扫中间按时长强弹新任务。守桥的第一次遭遇规模受限，让玩家有时间观察运输；合流的第一次外出不再叠加新一波空降。自由探索仍使用原有入侵规则。

停止追加 6、12、18 间的自动里程碑剧情。旧档已经收录的对白保留重听，但不再把累计清区数当新剧情资格。以后新增内容必须回答：它让玩家做出了什么新的选择、怎样改变原来的行动目的？若只有更大棋盘、重复刷资源或换一句台词，就不继续扩关。

参考：《潜水员戴夫》总监在 [Game Developer 访谈](https://www.gamedeveloper.com/design/dave-the-diver) 中讨论日夜任务分开后注意力改善，以及事件如何改变潜水的目标；[Xbox Wire 开发者文章](https://news.xbox.com/en-us/2025/11/20/dave-the-diver-xbox-partner-preview/) 回顾早期系统堆叠和教程过多的问题。采用的是引入时机与行动目的，不复刻其章节结构。

## 3. 世界结构与推进

每层是一张房间连接图。当前主题“归航灯塔”在 17×17 的布局范围内放置 127 间可达房间，全部正交连通，整体构成灯塔图案。每间房是独立棋盘，不是同一棋盘的裁切或放大窗口。自由探索的左右视图显示同一房间；新局第一次合流则以左侧外出、右侧桥头呈现前后方的联系。地图仅裁掉上下完全没有地面的空白行，不裁切可通行地面，桥梁与九宫格坐标同步。

每次按上下左右的门，立即进入相邻的独立房间；没有门的方向禁用。原房间雷区、标记、角色、营地和桥梁保留，可原路返回。全层图可返回已发现房间，首次进入必须与当前位置相邻。移动不推进回合。

单间有切角室、十字厅、转角厅、横向长廊、纵向长廊、T 形厅六类空间掩码。墙外空白不埋雷、不开格、不计清扫进度，也不能建设和供敌人落地。房间内部形状与整层轮廓是两个独立层级。

全层图显示房间间连接、未抵达/发现/清扫/敌占状态、人物和当前位置。扫清房间逐一金色点亮，最终完整图案被点亮。当前实现灯塔一种整体主题，后续可通过轮廓模板增加生命之树、鲸或其他有叙事含义的图形；不把尚未制作的主题列为已完成。

本层所有房间清扫完才开放下一层。旧层归档，人物、等级、原料继承。旧九区存档原样映射到灯塔底部，已有建设不重置。未游玩的房间改为自由首击。首次进入按需生成棋盘，避免一次生成全部 127 间。

## 4. 两套回合时钟

| 行为 | 行动回合 | 跨区回合 |
| --- | --- | --- |
| 左键开格、点数字展开或连标、插旗、取消旗、按标记巡检 | +1 | 0 |
| 重复点击已经打开的格子 | +1，但不重复领取清扫奖励 | 0 |
| 同一操作首次清完一个区域 | +1 | +1 |
| 重复操作已清完区域 | +1 | 0 |
| 移动、查看、角色选择、桥梁规划、培养、建家 | 0 | 0 |
| 剧情对话、暂停教学、清区庆祝对话框 | 0 | 0 |

已经开始、非整区敌占的区域随行动一起推进战斗和运输。未首击的房间冻结，不能提前囤积势力或错过入侵。空降另按该房间的主动清扫次数触发；在别处操作只推进已存在的交战，不触发远方新空降。整区敌占后，驻军只随新增清区事件成长一次；潜行清扫不额外给驻军刷增长。跨区队伍也只在新增清区事件结算，不允许一片已清完区域反复刷战略回合。

行动结算顺序：清扫/标记 → 获取新安全格奖励及救援 → 符合条件的节点增长 1 → 自动补给出发 → 所有在途包前进一格并结算到达 → 敌方事件/扩张 → 失守迁移 → 判断清区 → 跨区结算 → 庆祝反馈。

重复操作可主动等待。自然增长有容量，防止后方无限等待囤兵；主动清扫、数字奖励和运输可超过容量，已有高数值存档不削减。角色与敌方节点正交相邻时暂停自然增长，界面显示封锁提示，仍可用真实清扫和补给支援。阅读和观察永远不推进回合。

## 5. 扫雷与反馈

- 数字表示相邻八格雷数；九宫格围绕悬停、键盘聚焦或最后选中格，鼠标离开后保留。棋盘边缘裁剪到实际范围；房间墙外不计地雷。
- 整体延续地下站台的冷暗色调：未知格黑蓝，清扫地面冷灰，桥与营地留暖光；敌方和爆炸使用警戒红。
- 数字格保留低饱和色底与黑色数字：1 绿、2 黄、3 橙、4 红，后续逐渐加深；所有数字与底色对比度至少 4.5:1。
- 新房间没有固定预开格。玩家任选一个有效格作为第一步，首击安全；初始角色的大本营落在所选格。首击前插旗不锁定起点。
- 布雷数量按真实房型地面计算，墙外不参与密度或逻辑求解。首击九宫格和已有角色节点安全。使用限时逻辑求解筛选；达到尝试或时间预算仍无解时保留合法棋盘，因此当前不承诺所有房间绝对无猜。
- 左键开格，右键/F 标记，手机有开格/标记切换；周围旗数与数字匹配时，点击数字尝试打开其余格。误标仍可能爆炸。
- 若数字减去已知旗帜/爆炸数恰好等于剩余未知邻格数，点数字一次连标，仍只推进一回合。无确定结论时不替玩家猜雷。
- 显示待标雷数（总雷数减旗帜和爆炸）。归零后提供“按标记完成巡检”，一次打开剩余未标格、结算一个行动回合。它相信玩家的旗帜，误旗仍会触雷、损失原料；不是读取隐藏雷图保证安全的按钮。
- 新安全格轻微亮起/缩放，状态栏明确显示本次清扫和势力增量。有效清扫增援为 min(新安全格数, 5) + floor((角色等级−1)/2)，无新格或本次爆炸不给清扫增援。远方角色可接收，但隔两区以上有距离衰减。
- 地雷局部爆炸、闪光、震动、红色警报；邻近物资损毁并损失部分原料。不是一次踩雷全盘结束。当前不回退已开格，避免抹掉玩家已获得的信息；更复杂的进度惩罚留待平衡。
- 清完区域暂停游戏，展示全屏“这一区，亮起来了”、扩散光环、安全格数、跨区回合变化，点击继续恢复。减少动画偏好关闭震动与闪光。
- 新房间结算另显示本区行动数、原料收入和爆炸损失；已存在的旧房间不伪造历史收入。敌军普通扩张不覆盖刚完成的清扫提示。清区电台按房型变化，第 6/12/18 间有进度对白。
- 角色被发现、资源不足、无效桥路、区域失守、队伍抵达都提供可读反馈。

## 6. 单向桥、营地与逐格运输

玩家无需切换通行和驻扎模式。点击单格大本营或营地开始 → 鼠标沿安全格划出路线 → 点击空白终点驻扎。点击红色敌方据点作为终点则派队进攻。手机选中后可划线、松手确认；键盘方向键描绘、回车确认。

路线实时预览，可回扫撤回一段；快速直线划动可补齐中间格，不能凭空拐弯、穿越未知/墙壁/地雷。确认前不扣资源、不建半条桥，失败整笔拒绝。提交时显示数字收益、建设消耗和结果。

每格只服务一个阵营的一条单向连接。普通通路不能分叉，角色和营地可作为分支源。已有桥只允许沿原方向经过。

| 动作 | 消耗及结果 |
| --- | --- |
| 首次途经数字 n 的安全格 | 出发据点获得 n 势力，每格仅领取一次，防止往返刷数值 |
| 新延伸一格桥 | 支付 1 势力 |
| 空白终点驻扎 | 桥成本之外再支付 3，新营地初始势力 1 |
| 已占据节点 | 低于自然容量时每行动回合增长 1；被封锁角色暂停自然增长 |
| 敌方终点 | 支付最后一格延伸成本 1，留守 1，其余派出；逐格接敌并抵消敌方势力 |

例：路径三个数字 1、2、2 带来 5 势力，三格桥花 3、驻扎花 3，总消耗 6；18 势力大本营剩 17，终点营地初始 1。

角色到营地存在有向路径，且角色势力大于“营地现有 + 已在途补给”时，每回合自动发送 1。一个角色一回合最多发一个包。发送当回合移动一格，三格路线经过三次清扫行动到达。已出发包继续运送，尚未出发部分按差额判断。

**动画对应真实数据：** 新桥绘出连接动画；持续白点只表示方向，不影响数值。真实在途包带数字，从上一格移动到本格；到达时沿最后一段移动并闪现 +1。进攻队同样沿实际路径移动。逻辑只在玩家行动时结算，动画不产生额外回合。

实战教学使用独立训练地图，不改变正式存档。四步都需完成操作后点击下一步：选大本营并划过 1/2/2 预览 +5 → 点击终点支付 6 建营地 → 在左侧真实清扫四格，观察营地 2/3/5/7 的增长 → 从营地派出 5，清扫第五格后击败从 2 增长到 3 的入侵者，留下 2。教学不刷额外敌人，未派队前不会放行清扫；可随时退出或重练。阅读、观察、划线不推进回合。

进攻预览显示派出人数、到达回合、敌方自然增长后的估算及能否占领；不承诺包含其他增援和交战。同一路线有进攻队在途时阻止重复派出。实际运输到账显示 +1，攻击显示扣除或占领，不能混为补给奖励。接有桥梁的营地仍可被敌方攻击。

## 7. 角色、家与成长

**林渡 / 架桥人 / 单格大本营。** 原桥梁检修员，在桥上刻下走过者的名字。“桥的另一头，不应该只有回声。”

**岑灯 / 信号修复师 / 单格大本营。** 独自守着中继站，担心错过仍在求救的人。“我守着这台收音机，不是因为相信有人，是怕有人还在等。”

大本营只占一格，营地也只占一格。旧版多格家迁移时释放额外占地，累积势力合并回角色；身份和培养等级不丢失。当前交互使用划路线驻扎，不再显示多格选址或“通行/驻扎/根据地”模式切换。

培养花费 6×当前等级 + 3×(当前等级−1)² 原料，升一级并增加 4 势力。连续价格为 6、15、30、51、78、111、150，避免较大房间的收入让所有培养变成随手购买。每两级增加 1 点有效清扫增援，培养同时有主动收益。原料使用全层共享的远征库存，成功和不足均明确反馈。角色自然增长容量为 24 + 等级×8；普通营地为 12 + 层数×2 + 危险等级×2，敌方为 16 + 层数×2 + 危险等级×2。容量只停止自然增长，不截断主动收益。

“迁驻此区”将角色及等级、当前势力迁到已清出的安全空格，旧据点留下 1 势力营地。以人物与目标房间的曼哈顿距离计价：相邻 8、隔两区 10、三区 12、四区 14、五区以上 16 原料；界面在执行前显示准确费用。不消耗行动回合；敌占区需先收复。角色依然只占一格。

本区和相邻区获得全额清扫支援；其余地区将增援除以 1 + floor(距离/2)，向上取整，真实清扫至少获得 1。界面标出距离、衰减和实际到账。迁近能恢复支援效率，使培养单一强者、发展第二人物、支付迁驻费用成为不同选择。当前以房间距离近似通信损耗，尚未引入交通网络吞吐量模拟。

长期目标：不同角色带来独有生产配方；连通不同人物触发组合产品与关系事件。升级应改变生产/运输选择，不能只放大数值。

## 8. 入侵、失守、迁移与收复

敌人在格上空降，不沿传统塔防路径排队。单区首次空降在主动清扫第 12 + floor((边长−7)/2) 回合，提前 4 回合预告；第二次在第 30 + floor((边长−7)/2) 回合。界面显示剩余行动数。初始空降势力 6 + 层数 + 危险等级×2；每 6 间清区危险等级 +1，上限 4。前三级每 3 行动回合扩张一次，危险等级 3 起每 2 回合一次。所有战斗在玩家不操作时静止。

敌人优先向玩家据点施压并向前线补给，能够切断空置的玩家桥。攻击会积攒有意义的兵力再出发；不反复用 1、2 单位自杀，也不要求每次都一次性击破强敌。角色受邻接封锁后必须靠清扫支援、补给或迁驻脱困。

角色节点被击败，该区域转为敌占；没有角色的留守营地全部失守也会转为敌占。该区人物优先迁到无敌军的友好区域，再按距离选择，以 3 势力重建；保留身份及培养等级。没有已知落脚点时开放邻近可用房间。迁移暂停并显示明确事件，提供前往落脚点入口。新落脚点即刻安全可用，不会再次首击布雷覆盖人物。

区域失守后敌军整编为驻军，势力下限 6、上限 18 + 层数×2 + 危险等级×2；之后只随跨区回合增长且受自然容量限制。避免局部大战留下几百驻军而无法收复。入侵、失守、迁移、培养、迁驻和收复写入远征战报。

全层模式把每个独立房间缩成一个可辨形状的小节点。红点表示交战，红色房间表示敌占。选择“从当前房间派队”，再选相邻已发现房间，先预览出发数、敌方数和抵达条件，再确认。取本区最强据点，留下 1，连接消耗 1，其余派出；至少需 5，保证空区到达时有 3 建立前哨。同一条线路已有队伍时不能重复派出。

完成一个新的区域清扫，跨区队伍走一个区域距离；当前只开放相邻区域的一跳连接。与敌方区域总势力抵消，胜利后收复，并保留区域内尚存的友方角色。

**防死局规则：** 敌占区域仍可潜行清扫，清扫不自动改变其归属；架桥与建家需先收复。即使唯一未完成区域失守，玩家也可清完它，推动邻区收复队到达。所有房间完成后不再接受没有后续清区回合可结算的新队伍，可继续下层。

## 9. 叙事结构

开场是可玩的视觉小说序章「断桥的另一端」。林渡准备离开旧站台时，接到九号中继站岑灯的呼叫：电池快没了。她留下来送电池，玩家替她看路。清扫、桥、桥头营地、运输与抵抗灰帆分别成为这件事的一个步骤；每段短对话之后，玩家亲自操作。

首次进入铺桥练习，先播放一遍完整操作示范：移动光标经过 1、2、2，点击终点建立营地，左侧清扫推进补给逐格运输，最后派队击退红色据点。演示使用游戏引擎计算的独立快照，不更改练习或远征进度；可暂停、逐步看、选章节、重播或随时退出。亲自操作时仅保留三步指令，并高亮当前一步；点击终点立即驻扎，不再要求先翻到另一个教学阶段。教学限制在这条金色直线上，正式地图仍可自由描绘路线。

对话以原画和底部文字窗呈现，一句一屏，点击才继续；逐字文字可一键补全，也可切换即时显示。人物说具体的事，规则放在操作时的单条提示里。回看、暂离、刷新续读、独立演练保存均已接入。阅读期间棋盘和敌人暂停。

后续按实际进度触发：见到岑灯、第一座营地、第一间清区、首次灰帆入侵、失守撤离、收复旧家，以及 6/12/18 间里程碑和下层。失守先讲撤离，庆祝后再讲清区故事，避免同时弹多层窗口。旧存档的历史节点收入手记，首次更新时不连续补弹。

当前已实现序章和上述短场景；整层 127 间的长篇分支、更多场景原画及配音仍待制作。完整台词入口与触发说明见 [序章与叙事交互](地下回响-序章与叙事交互.md)。

## 10. 经济、科技与回收的后续 PRD

第一性原理科技链：安全地面 → 水与食物 → 简易机械/蓄电 → 有线通信 → 稳定能源 → 轨道运输 → 自动探测/回收。每次升级必须说明输入、能量来源、产物、维护和运输限制。

- 唯一交易货币在首次连接其他聚落后引入。材料是物品，势力是人口/行动能力，均不作为第二套交易币。
- 商人以节点事件出现，给予有限库存、绕路取舍与有截止回合的委托；不使用实时倒计时。
- 地雷回收需先标记、拆解/稳定，再转化为麻将牌；连连看作为回收工序，消除得到材料。不可凭空把未识别地雷直接变成资源。
- 生产具有投入成本、回收周期和运输延迟。可见的复利来自再投资扩大生产，瓶颈来自食物、维护、能源和距离，防止无限无成本指数增长。
- 人物组合配方：机械师 + 信号师 → 单格探测器；医生 + 农艺师 → 恢复用品。具体角色待写作。
- “遇见好友基地”先采用明确标注的离线投影/NPC 设定，真实联网与权限、断线恢复、安全校验另立范围，不能伪装成真人实时数据。

## 11. 验收与实现架构

引擎和界面分离：bridgeWorld 管单区扫雷/战斗/运输；campaignEngine 管区域/回合/迁移/家/战略队伍；roomLayout 管整层轮廓与单间形状；routeDrawing 管手势与交易；WorldMap 共用两种视图，BridgeOverlay 显示真实运输；WorldTour / ConnectionPractice 管教学。storyScript 只放剧本，storyProgress 管事件与续读，StoryScene 管呈现，叙事不结算战斗回合；路由协调交互和存档。

关键验收：

- 教学结束后九宫格仍存在；移出、键盘及移动端点击可保留观察范围。
- 一次有效清扫输入恰好一个行动回合；导航与布局不会偷偷推进；清区只奖励一次战略回合。
- 3 格运输恰好 3 回合，不瞬移；角色不强于营地时停止发货。
- 失守可迁移，培养不丢失；最后一区失守不会软锁。
- 空区不足 3 的队伍不会无声消失；收复不会删除友方角色。
- 一次穿门立即换独立棋盘，返回恢复原状态；127 间全部连通，墙外不参与任何游戏操作。
- 任意有效格首击安全；单格大本营；旧多格家收起时势力不丢失。
- 手势路径预览不修改世界，数字收益只领取一次；资源不足整笔回滚。
- 白点流向不产生数值；实际包逐格移动，到达记录支撑 +1 动画。
- 下层要本层所有房间清完，并保留人物、等级、原料；可恢复存档。
- 390px、768px、桌面没有横向溢出，教学和庆祝模态可键盘退出。

已对核心回合、运输、跨区、家和九宫格行为加入自动化测试。2026-10-27 长局实际从行动回合 61 玩到 111、清区 4 到 7、跨区回合 4 到 7；完成失守、保留培养迁移、后方恢复、邻区派出 41 对敌占 20、清扫结算后收复留下 21 的完整链路。操作从页面可见数字推断，未读取隐藏雷图或修改存档跳过战斗。具体过程和局限见《地下回响-长局试玩记录》。这验证了前期战役闭环，不代表 127 间整层及深层平衡已全部验证。

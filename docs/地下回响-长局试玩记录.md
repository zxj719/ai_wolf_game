# 地下回响 · 长局试玩与调整

2026-10-27 · 本地开发版 · 延续已有正式存档

## 实际走过的链路

使用页面左键、右键、数字展开、方向门和鼠标划线，按观察、推理、操作、看结果的节奏推进。没有批量自动点击通关，没有读取隐藏雷图，没有改存档制造胜利。为了覆盖失败分支，明确进行过一次兵力不足的进攻和一次过度抽调后方兵力。

| 阶段 | 页面实测结果 |
| --- | --- |

## 试玩发现与已实施调整

| 问题 | 调整及目的 |
| --- | --- |
| 后方每次操作永久 +1，久玩不必再清扫 | 增加自然增长容量；培养扩容。主动清扫、数字和运输仍可超容量，保留主动收益与积累价值 |
| 未开始房间偷偷长兵、错过精确入侵时间点 | 未首击房间冻结；空降使用本区探索计数和阈值判断；已有战斗继续随全局行动推进 |
| 全局显示库存，升级却只看角色所在房间库存 | 培养统一使用全层库存，明确显示成功、消耗与不足 |
| 不规则房型切掉太多地雷，首击几乎清全图 | 按真实地面数量布雷，并按真实地面邻接关系做逻辑筛选；同层每六间逐步扩图 |
| 敌军小股自杀，或双方每回合同步增长而永远打不掉 | 敌人积攒攻击兵力、优先补给前线；相邻敌军封锁角色自然增长，仍允许清扫救援 |
| 玩家桥梁成为不可攻击屏障 | 允许敌军切断无人据守的玩家桥，迫使玩家保护线路 |
| 失守后敌军总数太大，收复难以成立 | 占区驻军整编并限制自然增长，改用跨区时钟；保留邻区反攻机会 |
| 第一次实测撤离点仍在激烈交战中 | 优先无敌军后方再比较距离；保留等级、保证落脚格安全；增加主动迁驻 |
| 战略派队不知会派多少、剩多少 | 先预览再确认，留守 1、成本 1、其余出队；限制相同线路重复透支 |
| 远方变化难以察觉 | 迁移暂停提示、可定位战报、全层交战红点和敌占状态；补齐无角色营地失守的归属处理 |

## 验证边界

这是延续旧存档的实际长局，已有资源和势力可能高于新自然容量；为保护存档未回收旧积累。本轮没有将库存余额作为新开局资源产率统计，也没有据此强行提高培养价格。新局的原料获取速度、培养与迁驻支出占比还需要多局采样。

已实际走通前期探索到失守收复，覆盖 7×7 → 9×9 的递进。11×11、13×13 和深层规则有自动化覆盖，尚未逐间人工清完 127 间；不宣称整个后期已调平。限时棋盘筛选有合法兜底，不保证绝对无猜。

下一轮优先看：清扫和驻扎各占多少决策时间、玩家能否理解被封锁后的支援、角色培养是否比铺营地更有吸引力、相同布局重复探索是否疲劳。之后再引入生产与唯一交易货币，避免系统数量掩盖当前玩法的不足。

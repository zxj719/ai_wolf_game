# 地下回响：断桥的另一端

2026-10-27 · 本地实现记录

> 当前节奏已更新为 PRD v0.8 的“真实进度中的可选邀请”：新局先只扫雷，清出的房间再用于守桥，守住之后才合流。以下完整序章演练作为可选操作示范保留，不再是开场必过流程。6 / 12 / 18 间里程碑停止自动解锁；新局的剧情停止线和开放内容以 [PRD 2.1](./地下回响-PRD.md#21-当前故事的节奏和停止线) 为准。

## 这一版要解决什么

旧版把世界观写成标语，把剧情塞进地图上方的提示条，同时向玩家解释过多规则。玩家既不认识人物，也不知道眼前这一步为什么值得做。

新序章从一通求援电话开始。林渡正准备离开旧站台，岑灯的中继站快没电了。她决定留下来送电池，玩家替她看路。先有一件具体的事，规则随着完成这件事逐步出现。

人物语气：林渡话少、直接、习惯先把事情做好；岑灯有一点自嘲，紧张时会说日常小事。旁白只写能看见、听见的动作，不代替人物总结人生道理。没有配音，不自动播放音频。

## 序章节奏

1. 第一次通话：岑灯说电池快没了，林渡放下卷好的桥索。
2. 看路：人物对话后实际练习九宫格、开格、标雷、点数字展开。每一步成功后留下反馈，由玩家点下一步。
3. 铺桥：从林渡出发，鼠标经过 1、2、2；只预览路线，分清地面的雷数与据点的势力数。
4. 落脚：决定在桥头留一盏灯。实际点击终点驻扎，显示收入 5、建设 6、大本营剩余 11、营地从 1 开始。
5. 等补给：左侧清扫推动右侧运输，三格距离走三回合；四次操作后营地从 1 长到 7。
6. 守住中继站：灰帆来拆天线，人物对话暂停画面。玩家从营地出兵，再清扫一次，让 5 对 3 的救援抵达。
7. 接通：岑灯烧好热水，说不用带杯子。玩家主动结束序章，回到正式远征。

序章是可重玩的独立演练，不重置或修改正式战役。勘测图初级练习在当前步骤等待；桥梁演练保存棋盘、在途补给、路线、阶段和台词位置。

## 对话交互

- 原生模态 dialog 隔离背景操作。剧情期间清扫、迁驻、派队等入口禁用。
- 一次一段台词。逐字显示时，第一次点击补全当前句，第二次才换句。没有自动翻页。
- 点击底部正文或继续按钮都能推进；原生按钮支持键盘操作。
- 回看只包含当前场景已经读到的句子，避免剧透。
- 可在逐字和即时文字之间切换，偏好会保存；系统减少动态效果时默认即时文字。
- 稍后退出保留位置，顶部电台入口可继续；完成的场景可在电台手记里重听。
- 各战役按种子分别保存叙事进度。坏数据回退到序章，不碰战役数据。
- 新场景入队，当前场景完成后再读下一段。撤离优先，清区庆祝结束后再进入相关剧情。
- 旧存档只自动打开新序章；已经到达的历史节点收进手记，不连续补弹历史事件。

## 随实际进度出现的场景

| 触发 | 场景 | 教学或人物进展 |
| --- | --- | --- |
| 首次进入新版叙事 | 断桥的另一端 | 给玩家送电池的具体目标 |
| 救出岑灯 | 终于不用对着电台说话 | 选择角色接收清扫增援 |
| 第一座营地 | 留一盏灯 | 自然增长和自动补给 |
| 第一次清区 | 可以把鞋脱下来了 | 方向门通向独立房间，旧房建设保留 |
| 第一次空降 | 他们没有敲门 | 灰帆争夺电池，阅读不推进敌方行动 |
| 失守并撤离 | 先过桥 | 人物等级保留，说明实际落脚区域 |
| 第一次收复 | 名字还在 | 对先前失去家园的回应 |
| 清完 6 间 | 门上的字 | 有人来问路；介绍人物培养 |
| 清完 12 间 | 多出来的一声 | 开始收到回应；介绍迁驻与远程衰减 |
| 清完 18 间 | 有人听到了 | 岑灯的日常播报被听见；介绍跨区派队 |
| 进入下一层 | 把门留着 | 给后来的人留下通路图 |

## 实现位置

- `src/modules/games/expedition/storyScript.js`：人物声线、全套台词、结尾的单条操作提示。
- `StoryScene.jsx` / `story.css`：场景原画、台词框、逐字文字、回看与小屏布局。
- `storyProgress.js` / `useStoryProgress.js`：事件资格、排队、存档兼容与续读。
- `ConnectionPractice.jsx`：剧情和实际玩法交替的序章演练。
- `FieldGuide.jsx`：成功反馈停留，手动进入下一步。

## 实际验收

- 内置浏览器完整走完开场、九宫格三个动作、数字路线、驻扎、四回合补给、进攻、结尾通话；读取可见棋盘，没有写入浏览器隐藏状态跳过流程。
- 三格运输第三回合实际到账，营地按 1→2→3→5→7 成长，第五次清扫把红色据点收复。
- 开场第二句刷新后仍为第二句；已画好的路线刷新后仍可继续驻扎。
- 完成整个序章后正式战役仍为行动 424、跨区 20，没有被演练推进。
- 320 / 390 / 768 px 的剧情视图无横向溢出；320 px 的正文 17 px，继续按钮 44 px 高。
- 相关 14 个测试文件、70 项测试通过，包含剧情锁定背景、事件排队、旧档不补弹、续读、在途补给恢复、连点保护和原有玩法。
- 构建通过，45 个 JS 包通过地址泄漏检查。Vitest 退出时仍有仓库现有的 Vite 连接关闭超时提示，退出码为 0。

本轮覆盖可玩的序章和上述事件场景。整层 127 间的完整长篇剧情、剧情分支和配音不在本次完成范围内。未部署到线上。
